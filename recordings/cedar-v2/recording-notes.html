Recording context

What this walkthrough demonstrates

The complete Cedar walkthrough of the local GitHub Manager MVP, recorded October 13, 2026.

Real account, protected working state

The opening shows the authenticated account and a fresh GitHub sync. The account and visible repository metadata are unmasked, with the owner’s approval for public release. Password and OAuth authorization screens are excluded.

Editing, assignment changes, request-limit overrides, backend restart and destructive resets use an explicitly labeled copy of that real workspace. The working account’s organization and historical test evidence remain preserved.

AI results and local processing

The fresh taxonomy and classification checks use the public repositories allegro/ralph and acassen/keepalived. They demonstrate one bounded taxonomy generation and one single-repository classification, rather than claiming new inference across the entire account.

Saved real-model results and deterministic local matches are identified separately. Private README text and phrases derived from it remain outside the approved model-input path. The demo uses no synthetic repository inventory or fixture AI.

Organization belongs to the user

Domains contain Projects. Repositories may belong to multiple Projects. Topics describe reusable capabilities; Tags describe technologies or other specific labels. A repository with Topics or Tags can still have no Project.

Reviewed assignments and explicit rejections remain protected. Previous analysis is reused locally unless meaningful changes or an explicit reanalysis request justify fresh inference.

How the recording is edited

Pointer actions run at normal speed. Reading holds and disclosed discrete cuts shorten setup and waiting. Narration is not time-stretched. Captions follow recognized word timestamps; paragraph-level narration is aligned with its action or result scene.

Cedar is an AI-generated voice. The owner selected its calmer delivery through an earlier voice audition. Automated playback verifies technical behavior, not subjective naturalness.

Scope of validation

Local recording verification includes 117 feature assertions, 32 chapter seeks, 390 caption cues, 1080p decoding, fullscreen and responsive player layouts. Hosted playback is checked separately and reported on this site.

This is a recorded local MVP using Next.js, FastAPI and SQLite. Distributed workers, production DynamoDB/SQS deployment, broad model-quality evaluation and exhaustive GitHub organization/watch coverage remain separate gates. The site provides recordings; it does not run the application or request GitHub credentials.
